01 — 连接你的设备

一把密钥，同一个电台收藏夹。

  1. 使用一次性邀请码生成同步密钥，并私下保存。
  2. 打开 Mini Radio 的“收藏与收听同步”。
  3. 服务地址填写 https://radio.myaichatbox.com，在各台设备输入同一密钥，保存并启用。

新建空间需向服务维护者申请邀请码。已有同步密钥继续可用，无需重新生成。邀请码以发放时的有效期为准，只可使用一次。

邀请码已使用。持有密钥即可读取、修改和删除这个空间。不要放入公开截图、仓库或群聊；丢失后无法找回。

收藏会合，收听自在

收藏、自定义电台、取消收藏记录与最近 50 个收听电台自动合并。离线修改留在本机，下次联网继续同步。

每台设备，自己的节奏

同步不会打断正在播放的电台。音量、睡眠定时和窗口偏好保持独立。

数据如何保存

通过 HTTPS 传输，服务端加密存储收藏与历史；服务端持有存储密钥，能够解密。连接会暴露 IP 与请求时间。没有广告或行为分析 SDK。

停用密钥与删除云端数据

在应用内“停用同步”仅暂停当前设备。要停用所有设备的这把密钥并删除云端数据，请在这里输入密钥。本机数据与其他设备已下载的副本仍会保留；加密备份最多保留 7 天。
